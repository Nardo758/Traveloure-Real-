PLATFORM CONTEXT
================================================================

Traveloure is a three-party AI-powered travel 
marketplace at https://traveloure.com

Three parties:
- TRAVELERS: Plan trips, generate AI itineraries,
  book experts and experiences, purchase credits
- LOCAL EXPERTS: Get verified (6-step), receive 
  routed leads via 100-point scoring engine, 
  chat with travelers, earn via Stripe Connect
- SERVICE PROVIDERS: Get verified (7-step), 
  list services, receive bookings via expert 
  recommendations, earn via Stripe Connect

Tech stack:
- Frontend: React 18 + TypeScript + Vite + 
  Tailwind + shadcn/ui + Wouter routing
- Backend: Node.js + Express + TypeScript
- Database: PostgreSQL + Drizzle ORM
- AI: Grok (xAI) + Claude (Anthropic) 
  via AI Orchestrator
- Payments: Stripe + Stripe Connect + 
  Stripe Identity + Stripe Treasury
- External: Amadeus, Viator, Fever, SerpAPI, 
  12Go, Google Maps, Instagram API
- Hosting: Replit → traveloure.com

-- Trips with no owner

WHERE t.id IS NULL;
