Add rate limiting to heavy endpoints in Traveloure.

PROBLEM:
These endpoints have no throttle and can crash the 
database under load if hit repeatedly:
- GET /api/admin/* (revenue, users, bookings)
- POST /api/leads/route
- GET /api/admin/lead-routing-logs
- GET /api/itinerary-comparisons
- POST /api/ai/generate-itinerary (AI cost risk)

FIX REQUIRED:

1. Install express-rate-limit (only allowed new 
   package for this task):
   npm install express-rate-limit

2. Create server/middleware/rateLimiter.ts:

import rateLimit from "express-rate-limit";

// Admin endpoints — 30 requests per minute
export const adminRateLimit = rateLimit({
  windowMs: 60 * 1000,
  max: 30,
  message: {
    error: "Too many requests. Please wait 60 seconds."
  },
  standardHeaders: true,
  legacyHeaders: false,
});

// AI generation — 10 requests per minute per user
export const aiRateLimit = rateLimit({
  windowMs: 60 * 1000,
  max: 10,
  keyGenerator: (req) => req.user?.id || req.ip,
  message: {
    error: "AI generation limit reached. " +
           "Please wait before generating again."
  },
  standardHeaders: true,
  legacyHeaders: false,
});

// Lead routing — 20 requests per minute
export const leadRoutingRateLimit = rateLimit({
  windowMs: 60 * 1000,
  max: 20,
  message: {
    error: "Too many routing requests."
  },
  standardHeaders: true,
  legacyHeaders: false,
});

// Heavy read endpoints — 60 per minute
export const heavyReadRateLimit = rateLimit({
  windowMs: 60 * 1000,
  max: 60,
  message: {
    error: "Too many requests. Slow down."
  },
  standardHeaders: true,
  legacyHeaders: false,
});

3. Apply in routes.ts:

import { 
  adminRateLimit, 
  aiRateLimit,
  leadRoutingRateLimit,
  heavyReadRateLimit 
} from "./middleware/rateLimiter";

// Apply to admin routes
app.use("/api/admin", adminRateLimit);

// Apply to AI generation
app.post("/api/ai/generate-itinerary", 
  aiRateLimit, handler);
app.post("/api/trips/generate-itinerary", 
  aiRateLimit, handler);

// Apply to lead routing
app.post("/api/leads/route", 
  leadRoutingRateLimit, handler);

// Apply to heavy reads
app.get("/api/itinerary-comparisons", 
  heavyReadRateLimit, handler);
app.get("/api/admin/lead-routing-logs", 
  adminRateLimit, handler);

4. Do NOT change any existing route logic.
   Do NOT touch vite.config.ts or frontend files.
   Only add the middleware — nothing else.
