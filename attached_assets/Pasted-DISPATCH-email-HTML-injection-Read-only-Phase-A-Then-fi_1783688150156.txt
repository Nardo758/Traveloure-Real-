server/services/email.service.ts interpolates user-editable fields into raw
HTML template literals with no escaping, sent via Resend. React's escaping
does not apply. Confirmed sites: :144 userName, :164/:191/:201 bookingTitle
(body AND subject), :235/:270 providerName, :244 travelerName, :240/:285
serviceName, :315/:379/:638/:654 firstName, :488/:490 expert name.

    input. Sanitizing on write is the wrong layer — it corrupts stored data
    and misses fields written before the fix.
      const esc = (s: unknown) => String(s ?? "").replace(/[&<>"']/g, c => ({
        "&":"&amp;","<":"&lt;",">":"&gt;",'"':"&quot;","'":"&#39;" }[c]!));
