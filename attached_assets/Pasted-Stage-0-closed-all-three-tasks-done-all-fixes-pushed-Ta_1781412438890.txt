Task 2: Adults/kids audit
The original extracted handler did not pass adults or kids to createTrip — one of the 7 TypeScript errors in the dead router. At runtime, the DB would have defaulted to adults=2, kids=0, which would create inconsistent trips whenever inferredTravelers ≠ 2 (e.g., 5 travelers but 2 adults).
The inline fix sets adults = inferredTravelers, kids = 0. This makes adults + kids = numberOfTravelers, producing an internally consistent trip. There is no source for a kids breakdown in the cart context (contentMeta has travelers/numberOfTravelers but never adults/kids).
