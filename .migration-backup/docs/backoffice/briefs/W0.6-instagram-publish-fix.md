## Defect (verified)

`client/src/pages/expert/content-studio.tsx:308` calls
`apiRequest('/api/instagram/publish', {method:'POST', ...})` — the URL is passed in the **method** slot. The
real signature is `apiRequest(method, url, data)` (`client/src/lib/queryClient.ts:23-27`), so the request
never reaches the server. Also `content-studio.tsx:849` — the card dropdown "Post to Instagram" item has no
`onClick` (decorative).
