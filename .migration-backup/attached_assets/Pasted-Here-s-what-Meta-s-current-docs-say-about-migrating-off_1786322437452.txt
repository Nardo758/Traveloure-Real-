Here's what Meta's current docs say about migrating off Instagram Basic Display API for the Content Studio flow:

The replacement is called "Instagram API with Instagram Login" (also called Business Login for Instagram). Key differences from what your code currently expects: it does not require a linked Facebook Page (good — it's fully independent from the influencer sign-up flow's Facebook Login), users still need an Instagram professional (Business or Creator) account, and it uses new scope names: instagram_business_basic, instagram_business_content_publish, instagram_business_manage_comments, instagram_business_manage_messages — replacing the old instagram_basic etc. For your use case (pulling posts for Content Studio), you'd primarily need instagram_business_basic.

The technical shape is similar to before but on different infrastructure: users click your login URL, authorize on Instagram, get redirected to your registered redirect URI with an auth code, you exchange that for a short-lived Instagram User access token, then exchange that for a long-lived token (60 days, refreshable) — same general lifecycle as your current code, but the endpoints move to graph.instagram.com instead of api.instagram.com, and you'd need to add the "Instagram > API setup with Instagram login" product in the App Dashboard (with its own Instagram App ID/secret, separate from your main Meta App ID) and register a new redirect URI there.

One more thing worth flagging: since Content Studio would serve real outside experts (not just your team), you'd likely need Advanced Access via App Review and Business Verification for this too, similar to the Facebook Login permissions — Standard Access only covers people with a role on the app.
