# W0.2 — Knowledge-nugget API is role-ungated (any authenticated user)

**Tier:** Sonnet. **Migration:** none. **Est.:** ~30k tokens. Filed: FOLLOWUPS **M2**.

## Defect (verified)

`server/routes/expert-console.routes.ts:204-259` — the knowledge-nugget CRUD (GET/POST/PATCH/DELETE
`/api/expert/knowledge-nuggets`) is gated by `isAuthenticated` **only**. It is absent from
`EXPERT_SELF_SERVICE_PREFIXES` (`server/routes.ts:292-307`), so the `isExpert` backstop never applies, and
`expertConsoleRoutes` is mounted with no router-level role guard (`server/routes.ts:583`). Result: **any
logged-in user (including a traveler) can create/edit/delete nuggets.** The "local_expert-only" restriction
exists only client-side (`content-studio.tsx:205`).

Rows are owner-scoped by session (`expertUserId`), so this is a create-junk / unauthorized-write hole, not a
cross-tenant data leak — but it must be closed, especially since W0.x folds this tool into a shared Workspace.

## Scope

Pick ONE (prefer the first — it matches the existing pattern):
1. **Add `/api/expert/knowledge-nuggets` to `EXPERT_SELF_SERVICE_PREFIXES`** (`server/routes.ts:292-307`) so
   the `isExpert` backstop covers it (DB role lookup, expert roles + admin). This gates to *any expert role*.
   Then — because the composer is intended local_expert-only — **add a `local_expert`-or-admin check in the
   POST/PATCH/DELETE handlers** (read is fine for any expert), mirroring how other console handlers do a DB
   role lookup. (Matches the client's `isLocalExpert` gate.)
2. OR role-gate the four handlers directly to `local_expert`/`admin` at the router level.

Confirm the client (`content-studio.tsx`) still works for a local_expert and now 403s cleanly for a traveler.

## Traps

- Do NOT break the read path for the folded Workspace tool if the design later lets travel/event experts
  *view* nuggets — but per current intent the composer is local_expert-only, so gating writes to local_expert
  is correct. If unsure whether reads should be broader, gate writes only and leave GET at expert-level.
- The money guard must stay green — this file isn't money-named, but confirm no handler here does a money op.

## Gate

- Four standard gates.
- Behavioral: a seeded traveler (non-expert) session POSTing `/api/expert/knowledge-nuggets` gets 401/403
  (fails on the pre-fix code, which returns 200); a local_expert session still succeeds.
