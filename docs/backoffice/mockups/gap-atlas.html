Roadmap approval Decision

Phases 1–5 as corrected: Phase 1 cheaper (OG solved by pattern-copy; expert lanes largely done), Phase 2 bigger (attribution write path is dead, not dormant), Phases 4–5 smaller.

Instagram Tier-2: activate or stay dormant Decision

Server rail is built. Activation for experts is a one-line fix + env vars + a token-refresh job. The dispatch deferred Tier 2 on a premise the repo contradicts.

Coordinator compensation Decision

Assigned coordinators currently earn $0 on third-party vendor bookings. Deferrable — but then the earnings mockup drops its coordination slice, honestly.

Tip endpoint Decision

Live endpoint credits earnings with no charge (latent, zero UI callers). Recommend gating it now; build the payment leg only when a tip surface is actually scoped.
