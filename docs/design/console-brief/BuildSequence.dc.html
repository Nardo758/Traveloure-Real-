Build sequence

Eighteen lanes in four waves

A wave is a sequence, not a batch. Wave 1 can start before any ruling. Wave 2 waits on its ruling and on the lane it is blocked by. Wave 3 is the schema and the one lane that needs its own brief.
Every lane, per docs/OPERATING_PROCEDURE.md §3Branch task-<slug> off origin/main in its own worktree · one docs/DECISIONS.md row keyed YYYY-MM-DD-<slug> · every new test wired into build.yml · a new Playwright spec carries a spec-green line · CLAUDE.md delta only when a ruling is executed or amended · landed serially, one PR at a time · publish only through the preflight.
