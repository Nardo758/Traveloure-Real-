§16 rail

This is the rule that makes Phase 2 safe. The affiliate "book" button reuses the exact rail the Travelpayouts cards already use: POST /api/affiliate-booking-requests with an opaque bookingToken. The affiliate URL is stripped server-side and never reaches the browser — a booking agent (expert) fulfills it, preserving commission and preventing disintermediation.

No new outbound rail is created. No window.open(affiliateUrl) anywhere.

Four calls before I build · recommendations marked

What I need you to sign off

Q1

Where does the affiliate rung sit in the waterfall?

A ✓ Catalog → Affiliate → DMO ✓ chosen Own bookable inventory wins; partner-bookable beats informational. Mirrors the Trailhead "provider always wins, then affiliate" precedent.
B Catalog → DMO → Affiliate Prefer an informational pin over a partner booking. Quieter commercially; buries bookable partner inventory below a plain pin.
Q2

What do we match against? ✓ both

✓ Registry rows and live feeds — reconciled Match the persisted affiliate_products registry first (fast, deterministic). If nothing clears, best-effort consult live Travelpayouts feeds — and any live match is materialized into the registry (upsert by external_id) before it's linked, so the item's link and its §16 bookingToken always point at a real persisted row. This advances the §16 "one content home" consolidation instead of forking a second rail.
safety Live calls are best-effort & fail-closed A slow or failed feed never blocks or delays the build — the pass degrades to registry-only for that item (the same non-throwing posture as Phase 1). No live match is ever linked without clearing the same 0.82 name+geo gate.
Q3

Which affiliate rows are eligible to ground?

A ✓ Honor the bookingType classifier ✓ chosen affiliate_bookable → agent rail · in_platform_bookable → add-to-cart. The row already carries this; the CTA follows it. Unclassified rows stay unlinked (§13).
B Affiliate-bookable only, this phase Narrower: ground only partner-fulfilled rows via the agent rail; leave in-platform-bookable affiliate rows for later. Simpler, fewer branches.
Q4

How does affiliate grounding switch on?

A ✓ Lights up per market as inventory exists ✓ chosen No global flag — a market with no active affiliate rows simply grounds nothing on rung 02 and falls through. Honest by construction; no empty promises.
B Behind an explicit enable gate Keep it dark until a program is deliberately flipped on (the Trailhead T0 posture). Safer rollout control, but an extra switch to manage.
