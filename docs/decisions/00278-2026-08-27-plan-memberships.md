It is READ by the delivery side (the occasion-drafts entitlement gate) and WRITTEN by the separate Plus-checkout lane from the Stripe subscription webhook (`source='stripe'`) — that lane POPULATES it, it does not redefine it. **Trip Pass stays PER-TRIP (its home is `trip_entitlements`), never in this table**, since a trip pass is not a user-level membership. No UNIQUE(user, plan): history accrues as rows and `isActivePlus` matches any live one.
