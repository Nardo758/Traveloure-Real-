| 2026-08-31-mid-trip-purchase-versions | 2026-08-31 | [advisory] | **A MID-TRIP PURCHASE THAT ADDS A NEW ITEM TO A FINALIZED TRIP AUTO-CREATES v+1 — BUYING IS THE ACCEPTANCE (Trip Card rebuild Phase 4 rider; closes the last two-surfaces gap).** The two-surfaces model (`2026-08-31-two-surfaces-one-handoff`) froze the plan at Make-final and rendered the snapshot joined to LIVE booking status (`2026-08-31-trip-card-snapshot-render`). One gap remained: a service bought mid-trip via **Explore → Book now** writes a NEW confirmed item onto the trip (the affiliate-booking-agent confirm path, `server/routes/content.routes.ts` — the §16 agent rail's `createItineraryItem` on `status='confirmed'`), so on a finalized trip it was **paid for but absent from the frozen Trip Card until a manual re-final**. Fix: purchase completion now calls `reFinalizeIfCurrentlyFinal(tripId, owner)` — the traveler buying IS the acceptance, exactly the semantics already wired for suggestion-accept (`booking-actions.ts`) and adopt-stop (`plancard.routes.ts`), so the card advances to v+1 and the new item joins the snapshot. **The distinction that makes this safe:** a booking STATUS change on an item ALREADY in the plan is NOT a new item — the cart-checkout promotion (`markItemPurchased`, `checkout-claim.service.ts`) flips status and creates no item, so it never reaches this branch; and even a re-finalize would be a no-op because the finalize fingerprint (Phase 1) **excludes** `routing_status`/`booking_id`/`booking_status`/`actual_cost`/confirmation/references. So **status changes stay a live overlay; a new item joining the plan is a version** — the invariant stated cleanly. `reFinalizeIfCurrentlyFinal` only fires on a CURRENTLY-finalized trip (a never-finalized or reopened trip is left alone), and it is best-effort/non-fatal: the booking is the money truth, the version bump is a render convenience. With this, everything a traveler does mid-trip — accept a suggestion, buy a service, ask the Concierge — lands on their Trip Card without a trip to the workshop.
