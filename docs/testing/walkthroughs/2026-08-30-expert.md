## Findings

### F-E1 — `/local-experts` silently retitles to "Trip Planners" and shows trip-planner cards
- **CLASS:** JUDGMENT
- **SCREENSHOT:** `2026-08-30-expert/shot-04-local-experts-title.png`
- **WHAT HAPPENS:** Opening `/local-experts` with no `?role=` param renders a page **titled
  "Trip Planners"** whose cards are travel-expert (trip-planner) personas, not local experts.
  The initial role defaults to `local_expert` (`client/src/pages/experts.tsx:131-134`), but the
  Audit-A8 effect (`experts.tsx:225-235`: *"the default tab was hardcoded to 'local_expert' even
  when it has zero results"*) sees zero **public** local-expert results in this env and switches
  `selectedRole` to a role that has data (`travel_expert`), which re-drives the SEO title to
  "Trip Planners" (`experts.tsx:337-344`). There is **no on-page signal** that the user asked
  for Local Experts and is being shown Trip Planners instead.
- **WHY THE ZERO IS CORRECT:** the seeded Gion local expert (Mika) legitimately does **not**
  appear on the public directory yet — she has published no approved offering (dashboard shows
  "Open your business 0 of 4"), and the public gate lists only approved supply. So the empty
  local-expert result is the approval gate working (§13 / F2 read-side gate), **not** a data bug.
  The finding is purely the **silent role-swap** on top of that honest emptiness.
- **EXPECTATION VIOLATED:** CLAUDE.md §4 keeps local experts and trip planners as strictly
  separate roles ("Experts are NOT a service_category"). A `/local-experts` URL resolving to a
  "Trip Planners" page without saying so risks conflating the two in the user's mind. But the
  swap itself is **ratified behavior** (Audit A8 — don't strand the user on an empty tab), so
  whether it should be *signposted* ("No local experts here yet — showing trip planners") is a
  design judgment, not a rule violation.
- **FILE:LINE HYPOTHESIS:** `client/src/pages/experts.tsx:225-235` (the A8 auto-switch) + the
  title derivation at `experts.tsx:337-344`.
- **SEVERITY:** low–medium (correct in a stocked market; confusing only while local-expert
  supply is empty, which is exactly the launch window).
- **DISPOSITION:** **Escalate to Leon.** JUDGMENT class → never auto-fixed. Question: when A8
  swaps to a role with data, should the page announce the swap (an empty-state banner naming the
  requested role) rather than silently retitling?
